# Letzmeet

Letzmeet is a privacy-first adult relationship application. This repository is being initialized for code review of a **synthetic-data integration sandbox**, not a production service.

> Do not register real people or collect actual personal, payment, identity or health information using this implementation. Independent security review, POPIA checks, production auth, payment approval and a staffed moderation process are required before real-user release.

## Development

The integration sandbox is prepared in a feature branch. The original fictional-data team demo remains available separately. See `docs/IMPLEMENTATION_STATUS.md` and `docs/VALIDATION_REPORT.md` once the feature branch is created.
